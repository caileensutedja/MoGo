**How to run app:**
1. Clone this main branch
   Open terminal and run:
     git clone https://github.com/caileensutedja/MoGo.git
2. Navigate to the folder (and open it in Android Studio)
3. Create an Emulator (if needed), and run the project!


**To commit:**
1. Check status before commiting
   git status
2. Click Commit on the left side bar (2nd button - command+O)
3. Select files changed + write your commit message (important!!!)
   '''
   What did you changed/added/fixed
   What files are involved
   If not done yet write:
   - What needs to be done
   - What you need help with
   or write REVIEW for someone to recheck the file
   '''
4. Press "Commit and Push"
5. Check on GitHub and let the members know!

**Any assumptions or Progress**
Let the group know and write on your commit messages!
